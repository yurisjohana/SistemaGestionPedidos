# Sistema de Gestión de Pedidos para Tiendas de Barrio

Prototipo web sencillo elaborado a partir de los diseños y módulos definidos en evidencias anteriores del proyecto formativo ADSO.

## Módulos incluidos

- Inicio de sesión.
- Productos.
- Pedidos.
- Clientes.
- Inventario.

## Tecnologías de este prototipo

- HTML5.
- CSS3.
- JavaScript.
- Git y GitHub para control de versiones.

> Este repositorio corresponde a un prototipo web para evidenciar la aplicación del control de versiones. El proyecto formativo completo contempla otros componentes y tecnologías definidos en sus documentos de diseño.
